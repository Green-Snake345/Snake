## 📥 Как установить игру

⚠️ **Важно:** Для игры требуется подключение к интернету.

### 💻 Инструкция для Windows
**Вариант 1: Инсталлятор (Setup.exe) — Рекомендуется**
1. Скачайте файл **`Змейка Setup 1.0.6.exe`**.
2. Запустите его.
3. Если появится синий экран SmartScreen — нажмите **«Подробнее»** → **«Выполнить в любом случае»**.

### 🐧 Инструкция для Linux
**Вариант 1: Через терминал**
1. Откройте терминал.
2. Введите: `chmod +x Змейка-1.0.6.AppImage`.
