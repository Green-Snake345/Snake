=========================================
       ЗМЕЙКА - ИНСТРУКЦИЯ ПО УСТАНОВКЕ
=========================================

ВАЖНО: Для игры требуется подключение к интернету!
Убедитесь, что у вас есть сеть перед запуском.

-----------------------------------------
ИНСТРУКЦИЯ ДЛЯ WINDOWS
-----------------------------------------

У вас есть два варианта: Инсталлятор (рекомендуется) или Портативная версия.

Вариант 1: Инсталлятор (Setup.exe) - Рекомендуется
(Этот вариант поддерживает автоматические обновления игры в будущем).
1. Скачайте файл "Змейка Setup 1.0.6.exe".
2. Запустите его и следуйте инструкциям на экране.
3. ВНИМАНИЕ: Если появится синий экран SmartScreen ("Windows защитила ваш компьютер"):
   - Нажмите "Подробнее" (More info).
   - Нажмите "Выполнить в любом случае" (Run anyway).
   (Это стандартное предупреждение Windows для новых игр. Оно не означает, что в игре есть вирус).
4. После установки на Рабочем столе появится ярлык "Змейка".

Вариант 2: Портативная версия (ZIP)
Не требует установки.
1. Скачайте "Змейка-1.0.6-win.zip".
2. Распакуйте архив в любую удобную папку.
3. Запустите файл "Змейка.exe" из распакованной папки.
(Примечание: портативная версия не поддерживает автообновления).

-----------------------------------------
ИНСТРУКЦИЯ ДЛЯ LINUX
-----------------------------------------

Игра распространяется в формате AppImage. Ее не нужно устанавливать.

Вариант 1: Через графический интерфейс (Мышкой)
1. Скачайте файл "Змейка-1.0.6.AppImage".
2. Нажмите на него ПРАВОЙ кнопкой мыши и выберите "Свойства" (Properties).
3. Перейдите на вкладку "Права" (Permissions).
4. Поставьте галочку напротив пункта "Разрешить выполнение файла как программы".
5. Закройте свойства и дважды кликните по файлу, чтобы запустить игру.

Вариант 2: Через терминал
1. Откройте терминал в папке с игрой.
2. Сделайте файл исполняемым: chmod +x Змейка-1.0.6.AppImage
3. Запустите игру: ./Змейка-1.0.6.AppImage

ВОЗМОЖНЫЕ ПРОБЛЕМЫ НА LINUX:
- Ошибка FUSE: На новых версиях Ubuntu может появиться ошибка. 
  Установите библиотеку FUSE: sudo apt install libfuse2 (Ubuntu/Debian) 
  или sudo dnf install fuse-libs (Fedora).
- Сохранения: Настройки и рекорды сохраняются в скрытой папке ~/.config/Змейка/

-----------------------------------------
УПРАВЛЕНИЕ
-----------------------------------------
- Стрелки / WASD — движение
- Пробел — пауза
- F — развернуть на весь экран
- Shift — турбо
