# 🐍 Змейка

Собирай бусты, расти, не врежься в стены и зарабатывай монеты на новые скины. 
В игре есть ежедневные задания, комбо, магазин и поддержка геймпада.

## 🎮 Особенности игры
- 💰 **Экономика:** зарабатывайте монеты и покупайте уникальные скины в магазине.
- ⚡ **Бусты:** замедление, щит, магнит, лихорадка (x3) и режим призрака.
- 🔥 **Комбо-система:** ешьте еду быстро подряд для увеличения множителя очков.
- 📱 **Универсальное управление:** играйте на ПК (клавиатура) или на телефоне (свайпы и экранные кнопки).
- 🎨 **Кастомизация:** множество цветовых тем и стилей змейки.
- 📋 **Ежедневные задания:** выполняйте цели и получайте дополнительные награды.
- 📡 **Офлайн-режим:** играй без интернета после первой загрузки.
- 📳 **Вибрация:** тактильная отдача при сборе еды и столкновениях.
- 🔔 **Умные уведомления:** напоминания о ежедневных заданиях, если давно не играли.
- 📤 **Поделиться результатом:** отправьте свой рекорд друзьям в один клик.

  # 🎮 Управление и доступность:
  - 🎮 **Поддержка геймпадов:** играй с контроллером Xbox/PlayStation.
  - ⚡ **Турбо-режим:** ускорение по кнопке Shift или двойному тапу.
  - ♿ **Доступность:** режимы для дальтоников, уменьшенная анимация, высокая контрастность.
 
    # 🏆 Прогрессия:
    - 🏆 **Таблица лидеров:** отслеживай свои топ-5 результатов.
    - 🎁 **Ежедневные бонусы:** заходи каждый день за наградами.
    - 🏅 **Достижения:** разблокируй награды за особые достижения.
